# 🧟 Zombie Night

A polished, responsive, top-down survival game built with **HTML5, CSS3, and Vanilla JavaScript**.

Survive endless zombie waves, upgrade your stats, unlock powerful weaponry, and fight until dawn!

---

## 🎮 Features

- **Day & Night Cycle System**: Dynamic canvas darkness overlay with flashlight illumination beam, streetlights, and night spawner aggression scaling.
- **Dynamic Zombie Archetypes**:
  - **Walker Zombie**: Standard medium health and speed.
  - **Runner Zombie**: Fast, feral posture, low health.
  - **Tank Zombie**: High health, heavy impact damage.
  - **Titan Boss Zombie**: Massive health bar, ground stomp shockwaves, high rewards!
- **Arsenal of Weapons**:
  - 🔫 **Pistol**: Balanced starter sidearm.
  - 💥 **Shotgun**: High burst multi-pellet spread.
  - ⚡ **SMG**: Rapid automatic firing.
  - 🎯 **Assault Rifle**: High velocity, penetrative rifle rounds.
- **Character Upgrades & Armory Shop**: Inter-wave shop to upgrade Max Health, Speed, Fire Rate, Damage Output, Coin Magnet, and Dash Cooldown.
- **Special Events**: Randomly triggered *Horde Incoming!*, *Supply Drop Crates*, and *Blood Moon Enrage*.
- **Procedural Sound Engine**: Web Audio API sound synthesizer with zero external sound file dependencies!
- **Full Mobile & Desktop Support**: Desktop mouse/keyboard controls + Mobile Virtual Joystick & Touch Action buttons.
- **Save System & Leaderboard**: LocalStorage persistent High Scores, Coins, and Upgrades.

---

## 💻 Tech Stack

- **HTML5** & **Canvas API** for 2D graphics rendering.
- **CSS3** (Glassmorphism UI, custom dark horror aesthetics, responsive flex/grid layouts).
- **Vanilla JavaScript (ES6+)** with zero external libraries or framework dependencies.
- **Web Audio API** for synthesized sound effects and dark ambient horror soundtrack.
- **LocalStorage API** for client-side save persistence.

## 🕹️ Controls

### 🖥️ Desktop
- **WASD** / **Arrow Keys** — Move Player
- **Mouse Cursor** — Aim Weapon
- **Left Click** — Shoot
- **R** — Reload Weapon
- **1**, **2**, **3**, **4** — Switch Weapon
- **Spacebar** — Dash / Evade
- **ESC** / **P** — Pause Game

### 📱 Mobile / Tablet
- **Left Virtual Joystick** — Drag to move character
- **Shoot Button** — Tap or hold to fire weapon
- **Reload Button** — Quick reload
- **Dash Button** — Quick dodge

## 🚀 Live Demo & Deployment

This game is 100% static and deployable directly on **GitHub Pages**:

1. Push this repository to GitHub.
2. Navigate to **Settings** -> **Pages**.
3. Select the `main` branch and `/ (root)` folder, then click **Save**.
4. Play immediately in your browser!
